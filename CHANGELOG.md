# Changelog

## 1.1.0 - 2026-08-19

- Renamed npm package target to `compilescent-media-downloader` for reliable public install.
- Rebuilt the TUI as an arrow-key interactive interface with graceful non-TTY fallback.
- Added queue mode, format listing, playlist opt-in, metadata, thumbnail, browser cookies, and concurrent fragment options.
- Improved CLI help, README, keywords, and professional package metadata.

## 1.0.0 - 2026-08-19

- Initial public release.
- Added dependency-free TUI.
- Added yt-dlp presets, progress display, history, and doctor command.
- Added Compilescent branding assets.
